# The Cottage★ — Motion Design Intro

This repository contains the visual concept, editable scene artwork, animated browser prototype, and Remotion source project for the 45-second Cottage★ introduction.

> The Cottage★ is the home. The SMP is the backyard.

## Start here

1. **[Browse the seven scene artworks](assets/scenes/)** — editable landscape SVG compositions.
2. **[Open the animated browser preview source](preview/index.html)** — seven scenes, timed playback, and a 16:9 / 9:16 composition switch. Download the HTML and open it in a browser; GitHub's code viewer does not execute it.
3. **[Open the Remotion project](remotion/)** — editable React/TypeScript video source configured for 120 FPS and separate landscape and portrait compositions.
