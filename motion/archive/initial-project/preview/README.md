# Open the animated preview

1. Open [index.html](index.html).
2. Use the **Raw** button, then save the page as `index.html` (or use the download option in your browser).
3. Open the saved file in Chrome, Edge, Firefox, or Safari.
4. Press **Replay** to restart the 45-second sequence.
5. Press **Switch to 9:16** to inspect the vertical layout.

The preview is a self-contained HTML/CSS/JavaScript prototype. It needs no npm install, build step, account, or external assets.

GitHub's code viewer displays the source; it does not execute the preview in the repository page.

This is not the final 120 FPS MP4. Browser playback speed is controlled by the browser and display refresh rate.
