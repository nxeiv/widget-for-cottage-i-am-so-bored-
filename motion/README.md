The active production project reads the original photographs and artwork from the repository's existing `Media/` directory. Keep new approved reference images there; do not create duplicate copies unless we need a specific edit or optimized export.

The active creative direction is photo-led and human: real Cottage★ moments, warm film grain, soft focus, imperfect scrapbook framing, handwritten-feeling details, and emotional pacing. Avoid generic stock-like illustrations, synthetic people, and overly symmetrical AI-poster layouts.
